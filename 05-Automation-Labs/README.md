# 05-Automation-Labs

**Focus:** Folder for automation and security engineering labs in Azure.

---

## Purpose

This folder contains labs for **Phase 6 — Automation & Security Engineering**, including:

- Deploying and managing Azure VMs via CLI.
- Testing and enforcing network segmentation using NSGs.
- Practicing jump-host architecture for secure internal access.
- Learning VM lifecycle management for cost efficiency.

---

## Notes

- Each phase lab is self-contained inside its subfolder.
- Observations and commands are stored in the respective lab folder.

# Azure Cloud Security Labs

This repository contains hands-on labs and projects designed to demonstrate practical cloud security skills in Microsoft Azure. It documents my journey learning cloud security concepts, implementing them in a live Azure environment, and testing real-world security scenarios.

## Objective
The goal of this repository is to build a portfolio of cloud security labs that showcase my understanding of:

- Identity and Access Management (IAM) and Role-Based Access Control (RBAC)
- Azure Networking and Network Security Groups (NSGs)
- Virtual Machines and resource management
- Monitoring, logging, and threat detection using Azure tools
- Security hardening and best practices in a cloud environment

## Structure
Each lab is organized into its own folder with:

- `README.md` – Lab objectives, steps, observations, and takeaways  
- `screenshots/` – Images demonstrating the lab setup and outcomes  
- `scripts/` (if applicable) – CLI, ARM templates, or automation scripts  

## Skills Demonstrated
- Microsoft Azure portal and services  
- Azure Active Directory / Entra ID  
- RBAC and least privilege access  
- Network security and segmentation  
- Cloud monitoring, alerting, and threat detection  
- Security best practices and compliance

## How to Use
1. Follow the step-by-step instructions in each lab’s README.  
2. Optional: Use your own Azure subscription to reproduce the labs.  
3. Screenshots are included to demonstrate expected outcomes.  

## Notes
- Sensitive information (such as object IDs, subscription IDs, and passwords) has been removed or masked for security purposes.  
- This repository is intended for educational purposes and portfolio demonstration.

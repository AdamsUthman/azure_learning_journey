# Security Policies Labs

This folder contains labs focused on **identity security, policies, and secrets protection**.

Topics covered:

- Security Defaults
- Multi-Factor Authentication (MFA)
- Conditional Access basics
- Break-glass admin accounts
- Key Vault
- Secrets management
- RBAC for Key Vault
- Storage security

Goal:

Understand how to protect identities, secrets, and sensitive resources in Azure.

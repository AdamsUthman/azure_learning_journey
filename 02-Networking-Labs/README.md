# Networking Labs

This folder contains labs focused on **Azure Virtual Networking and Network Security**.

Topics covered:

- Virtual Networks (VNet)
- Subnets
- Network Security Groups (NSG)
- Allow / Deny rules
- VM connectivity testing
- SSH / ICMP testing
- Subnet-level security

Goal:

Understand how to secure traffic inside Azure and control access between resources.

Labs:

- phase2-NSG-configuration
- phase3-VM-testing
